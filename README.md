# MATCHDAY — 무료 호스팅 + 실시간 데이터 연동 가이드

이 폴더에는 매치데이 사이트 전체 파일이 들어 있어요 (`index.html`, `manifest.json`, `sw.js`, 아이콘, `live-data.js`). Claude 아티팩트와 달리, 외부로 배포하면 브라우저에서 실제 API를 직접 호출할 수 있어서 진짜 실시간 데이터 연동이 가능해져요.

## 0. 최근에 정리한 "가짜 정보" 문제 (중요)

예전 버전엔 실제 팀/선수 이름에 지어낸 스코어·경기 리뷰·전력 분석·상대전적·뉴스 헤드라인을 붙여서 보여주는 부분이 많았어요(데모 목적으로 만든 예시 데이터였는데, 실제 데이터처럼 보일 수 있는 문제였어요). 전부 찾아서 없앴어요:

- 경기 종료 후 뜨던 서술형 리뷰·하이라이트 문장 → 삭제, 대신 실제로 아는 정보(날짜·장소·최종 스코어)만 보여줘요.
- "주요 선수" 카드 → 무작위로 실제 선수 이름을 배정하던 방식 삭제, 대신 각 팀 이름으로 실제 검색 결과를 열어주는 링크로 교체.
- "최근 맞대결" 상대전적 → 지어낸 기록이라 완전히 삭제.
- 홈 화면 "맞춤 뉴스"와 경기 상세의 "관련 뉴스" → 가짜 헤드라인 목록 삭제, 실제 네이버 검색 링크로 교체.
- 홈 화면 순위표 → 지어낸 승점이라 비웠어요(실제 순위표 API 연동은 아직 안 했어요).
- 페이지가 열리자마자 보이던 "예시 경기" 목록 자체를 없앴어요. 이제 실시간 데이터를 받아오기 전까지는 "실시간 경기 정보를 불러오는 중이에요…"라고 정직하게 표시되고, 아직 연동 안 된 종목(격투기)은 "경기가 없어요"로 남아요(로딩 중이 아니라 연동이 안 된 상태라는 뜻이에요).

배당률(%)·승률 시뮬레이션 지수·폼(최근 5경기)·모의 투자·커뮤니티 예측은 여전히 화면 구성을 위한 시뮬레이션 값이에요. 이것도 실제 통계가 아니라는 걸 화면 상단 안내 문구와 각 섹션에 명시해뒀어요.

## 1. 사이트 배포 — GitHub Pages (무료, 추천)

1. github.com 에서 새 저장소(repository)를 만들어요. (Public으로)
2. 이 폴더의 파일을 그대로 저장소에 업로드해요: `index.html`, `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png`, `live-data.js`.
3. 저장소 `Settings → Pages`에서 Source를 `main` 브랜치, 루트(`/`)로 설정하고 저장해요.
4. 1~2분 후 `https://<사용자아이디>.github.io/<저장소이름>/` 주소로 사이트가 열려요.
5. 모바일에서 그 주소로 접속 후 "홈 화면에 추가"를 누르면 앱처럼 설치돼요.

## 2. 실시간 데이터 연동 — 지금 구조 (2번째 개편)

```
브라우저(사이트) ──▶ TheSportsDB (축구 K리그1 / 야구 KBO / 농구 KBL / 배구 V리그) — 키 숨김 불필요, 직접 호출
              └──▶ OpenF1 (F1, 키 불필요, 직접 호출)
```

**중요한 변경사항**: 원래는 api-sports.io + Vercel 프록시(`vercel-proxy/` 폴더, 키를 숨기기 위한 중계 서버) 구조였는데, 실제로 붙여서 테스트해보니 **api-sports.io 무료 플랜은 2026년 같은 "현재 시즌" 데이터에 아예 접근이 안 되고 2022~2024년 과거 시즌만 허용**된다는 게 확인됐어요 (`"Free plans do not have access to this season, try from 2022 to 2024."` 에러). 유료 결제 없이는 애초에 "실시간 현재 경기"라는 목표 자체를 이룰 수 없는 구조였던 거예요.

그래서 **TheSportsDB**(thesportsdb.com)라는 다른 무료 API로 축구/야구/농구/배구 4종목을 통째로 옮겼어요. TheSportsDB는 `"123"`이라는 공개 테스트 키를 회원가입 없이 그대로 쓸 수 있고(공식 문서에 명시된 값이라 숨길 필요가 없어요), 실제로 2026년 현재 시즌 K리그1/KBO/KBL/V리그 경기가 나오는 걸 직접 호출해서 확인했어요. 덕분에 프록시 서버가 아예 필요 없어졌어요 — `live-data.js`가 브라우저에서 TheSportsDB를 바로 호출해요.

`worker.js`와 `vercel-proxy/` 폴더는 이제 이 4개 종목에는 쓰이지 않지만, 나중에 유료로 격투기(MMA) API를 붙이게 될 경우를 대비해서 폴더에 남겨뒀어요. 지금 당장은 무시하셔도 돼요.

### 2-1. 확인된 TheSportsDB 리그 번호

- K리그1: `4689`
- EPL(프리미어리그): `4328`
- KBO: `4830`
- KBL: `5124`
- V리그(남): `5757`
- V리그(여): `5756`

> EPL(4328)은 실제로 호출해서 2026년 현재 시즌 경기가 나오는 걸 확인했지만, TheSportsDB 쪽 팀 소속 정보가 승격/강등 직후엔 살짝 오래된 경우가 있었어요(테스트 중 챔피언십 소속 팀이 하나 섞여 나온 적이 있어요). 콘솔의 `raw sample` 로그로 이상해 보이는 경기가 있으면 알려주세요.

전부 `live-data.js`의 `LEAGUES`에 이미 넣어뒀어요. 다른 해외 리그(EPL, MLB 등)를 추가하고 싶으면 말씀해주시면 리그 번호를 찾아서 추가해드릴게요.

### 2-2. live-data.js 연결

1. `index.html`에는 이미 `<script src="live-data.js"></script>`가 연결돼 있어요. 별도 설정 없이 `live-data.js` 파일만 사이트 저장소에 같이 올리면 바로 동작해요.
2. 배포 후 사이트를 열고 브라우저 개발자도구(콘솔)를 확인하세요. 각 종목의 실제 API 응답이 `[live-data] ... raw sample`로 콘솔에 찍혀요 — 필드가 이상하면 알려주시면 매핑 코드를 바로 고쳐드릴게요.
3. TheSportsDB 무료 키는 분당 30회 제한이 있어요. 너무 자주 새로고침하면 잠깐 막힐 수 있지만, 페이지 로드할 때 한 번만 호출하므로 일반적인 사용에서는 문제 없어요.

### 2-3. F1은 별도 설정 없이 자동 동작

F1은 OpenF1(api.openf1.org)을 키 없이 직접 호출해서 `live-data.js`만 연결하면 바로 동작해요.

**F1 표시 방식에 대한 솔직한 안내**: 지금 사이트는 축구/야구 같은 종목과 화면 틀(스코어, 승패 폼, 상대 전적)을 똑같이 맞추기 위해서, F1 레이스를 "상위 2명 드라이버의 가상 대결"처럼 표시하고 있어요(1위/2위 순위를 마치 점수처럼 보여주는 방식). 실제 레이스는 20명이 겨루는 경기라 이 방식이 어색하게 보일 수 있어요 — 원하시면 F1/모터스포츠는 아예 다른 화면 틀(전체 순위표 형태 등)로 새로 디자인해드릴 수 있어요.

### 2-4. e스포츠(LCK) — PandaScore + Vercel 프록시

TheSportsDB와 api-sports.io 둘 다 e스포츠 상품이 없어서, **PandaScore**(developers.pandascore.co)라는 e스포츠 전문 API를 따로 붙였어요. PandaScore는 무료 티어(Fixtures 플랜)로 일정·결과를 제공하지만, ① 회원가입 후 발급받는 키가 필요하고 ② 브라우저에서 직접 호출하는 걸 막아놔서(CORS 미지원 + "클라이언트에 키 노출 금지"라고 문서에 명시) TheSportsDB/OpenF1처럼 바로 호출할 수 없어요. 그래서 축구/야구/농구/배구용으로 이미 만들어둔 `vercel-proxy` 폴더에 `/api/esports/...` 경로를 추가해서, 이 프록시를 거쳐 안전하게 호출하도록 했어요.

1. https://developers.pandascore.co 무료 가입 → 대시보드에서 API 토큰 발급.
2. `vercel-proxy` 폴더 전체(새로 추가된 `api/esports/[...path].js` 포함)를 기존에 만들어둔 Vercel 프로젝트(예: `matchdayvercel`) 저장소에 다시 올려주세요. GitHub에 push하면 Vercel이 자동으로 재배포해요. (프록시를 아직 한 번도 안 만드셨다면 2-2 순서대로 새로 만들어도 돼요.)
3. Vercel 프로젝트 → `Settings → Environment Variables → Add`
   - Key: `PANDASCORE_KEY`
   - Value: 1번에서 발급받은 토큰
   - `Save` → `Deployments` 탭에서 최신 배포 옆 `...` → `Redeploy`
4. `live-data.js` 맨 위 **`ESPORTS_WORKER_BASE`**에 그 Vercel 프로젝트 주소를 넣어주세요 (예: `"https://matchdayvercel.vercel.app"`, `WORKER_BASE`와 같은 주소면 돼요).
5. 배포 후 콘솔에서 `[live-data] esports (PandaScore) raw sample` 로그가 찍히는지, LCK 리그가 정상적으로 검색되는지 확인해주세요. (LCK 리그 번호는 하드코딩하지 않고 매번 `search[name]=LCK`로 찾도록 짰어요 — PandaScore 쪽 번호가 바뀌어도 계속 동작해요.)

> PandaScore 무료 티어는 정확한 요청 제한이 공개 문서에 나와있지 않아요(유료 플랜은 시간당 1,000건). 트래픽이 많아지면 막힐 수 있으니, 문제가 생기면 알려주세요.

### 2-5. 정확도에 대한 솔직한 안내

- K리그1(4689)/KBO(4830)/KBL(5124)/V리그(5757,5756)는 실제로 호출해서 2026년 현재 시즌 데이터가 나오는 걸 확인한 번호예요.
- 축구/야구/농구/배구 상태값(`strStatus`)이 종목마다 조금씩 다르게 올 수 있어서 라이브 진행 중 표시가 100% 정확하지 않을 수 있어요 — 콘솔 로그를 보고 이상하면 알려주세요.
- OpenF1(F1) 필드명은 openf1.org 공식 문서에서 직접 확인한 내용이에요.
- UFC/격투기(MMA)는 자동 연동을 넣지 않았어요.

## 3. 지금 이대로도 동작해요

`live-data.js`를 연결하지 않으면 지금처럼 예시 데이터로 정상 작동하는 사이트예요. 준비되는 대로 하나씩 연동하면 되고, 언제든 이어서 요청해주시면 다음 단계(격투기/e스포츠 연동, 다른 해외 리그 추가, F1 화면 재설계 등)를 진행해드릴게요.
